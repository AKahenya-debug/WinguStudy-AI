# WinguStudy AI ☁️

**Understand the Cloud. Learn Your Way.**

## About the Project

WinguStudy AI is a beginner-friendly Azure study companion created for the hackathon theme:

**Building Smarter Exam Prep Tools From Our Own Journey.**

The project addresses the challenge of understanding abstract cloud computing concepts, particularly for beginners preparing for the Microsoft Azure Fundamentals (AZ-900) certification.

## Problem Statement

Cloud computing concepts can feel abstract and difficult to understand, especially for learners who are new to technology.

WinguStudy AI aims to make these concepts easier through simple explanations, relatable African examples, and interactive learning activities.

## Key Features

- Beginner-friendly Azure learning modules.
- Simple explanations of cloud computing and Azure services.
- Real-life African examples.
- AI-powered study assistance, where configured.
- Original practice questions and quizzes.
- Learning progress tracking.

## Learning Modules

1. **Cloud Concepts** — cloud computing and cloud service types.
2. **Azure Architecture and Services** — architecture, compute, networking, storage, identity, access, and security.
3. **Azure Management and Governance** — cost management, governance, deployment, and monitoring tools.
