# PROJECT: WinguStudy AI — Your Azure Study Buddy

## 1. Project Overview

Build a modern, responsive, beginner-friendly educational website called **WinguStudy AI**.

**Tagline:** Understand the Cloud. Learn Your Way.

The project is being developed for a beginner software engineering hackathon under the theme:

**"Building Smarter Exam Prep Tools From Our Own Journey."**

The goal is to help beginners preparing for the Microsoft Azure Fundamentals (AZ-900) certification understand cloud computing and Azure concepts without feeling overwhelmed by technical language.

The website should act as an interactive AI study buddy that explains difficult cloud concepts in simple English, uses relatable African examples, provides original practice questions, and helps learners identify areas where they need more revision.

Display a clear disclaimer stating that WinguStudy AI is an independent learning tool and is not officially affiliated with, endorsed by, or sponsored by Microsoft.

## 2. Problem Statement

Cloud computing concepts can feel abstract and confusing, especially for beginners who are learning about cloud services, infrastructure, networking, storage, security, and governance for the first time.

Traditional study materials can sometimes feel too technical or disconnected from everyday experiences.

WinguStudy AI addresses this problem by translating complex Azure concepts into simple explanations, relatable African examples, short revision notes, and interactive practice activities.

## 3. Target Users

The website is designed for:
- Beginners learning cloud computing.
- Students studying software engineering or information technology.
- Learners preparing for the AZ-900 certification.
- African learners who benefit from familiar real-life examples.

## MODULE 1: CLOUD CONCEPTS

Provide a short introduction explaining what cloud computing is and why organizations use it.

### 1.1 Cloud Computing

Explain cloud computing as the delivery of computing services, such as servers, storage, networking, and software, over the internet.

Briefly explain:
- What cloud computing means.
- Why organizations use cloud services.
- Benefits such as scalability, flexibility, availability, and reduced upfront infrastructure costs.
- The difference between CapEx and OpEx.
- Public, private, and hybrid cloud models.
- The shared responsibility concept.
- Consumption-based pricing.

African example:
Explain cloud computing using a small Kenyan business that stores customer records and runs its online shop using cloud services instead of purchasing and maintaining its own physical servers.

### 1.2 Cloud Service Types

Explain the three main cloud service models:

**Infrastructure as a Service (IaaS):**
Provides virtualized computing resources such as virtual machines, storage, and networking. The customer manages the operating system and applications, while the provider manages the underlying physical infrastructure.

Example: A Kenyan startup rents virtual servers instead of buying physical computers for its server room.

**Platform as a Service (PaaS):**
Provides a platform for building and deploying applications without requiring the customer to manage the underlying operating system and physical infrastructure.

Example: A software developer deploys a school management application without managing the physical servers.

**Software as a Service (SaaS):**
Provides ready-to-use software over the internet, usually through a browser or application.

Example: A school uses a cloud-based email or document collaboration service.

Include a simple comparison showing what the cloud provider manages and what the customer manages under each model.

## MODULE 2: AZURE ARCHITECTURE AND SERVICES

Introduce Microsoft Azure as a cloud computing platform offering services for computing, networking, storage, identity, security, and more.

Explain each of the following subtopics in simple terms.

### 2.1 Azure Architectural Concepts

Cover:
- Regions: Geographical areas containing Azure datacenters.
- Availability zones: Separate locations within supported Azure regions that help protect applications against datacenter-level failures.
- Region pairs: Certain Azure regions paired for specific resilience and disaster recovery considerations.
- Azure resources: Individual cloud components such as virtual machines, databases, and storage accounts.
- Resource groups: Containers used to organize and manage related Azure resources.
- Subscriptions: Units used for billing, access management, and resource organization.
- Management groups: Structures used to organize subscriptions and apply governance across them.

African example:
Explain resource groups using a school project where the classrooms, library, computers, and other facilities are grouped under one school administration structure.

### 2.2 Azure Compute Services

Explain:
- Azure Virtual Machines: Virtual computers hosted in Azure.
- Azure App Service: A platform for hosting web applications and APIs.
- Azure Functions: A serverless service that runs code in response to events.
- Azure Virtual Machine Scale Sets: Groups of virtual machines that can scale according to demand.
- Containers: Lightweight environments for running applications consistently.
- Azure Container Instances and Azure Kubernetes Service: Services for running containers, with Kubernetes Service supporting container orchestration.
- Azure Virtual Desktop: A service for delivering virtual desktops and applications.

African example:
Explain how a Kenyan e-commerce website can use virtual machines or application hosting to serve customers and handle increased traffic during a major sales promotion.

### 2.3 Azure Networking Services

Explain:
- Azure Virtual Network: A private network for Azure resources.
- Subnets: Smaller network sections used to organize and isolate resources.
- Network Security Groups: Rules that control permitted network traffic.
- Azure VPN Gateway: Encrypted connections between Azure networks and other networks over the internet.
- Azure ExpressRoute: Private network connectivity between an organization's network and Microsoft cloud services.
- Azure DNS: A service for hosting and managing DNS domains.
- Azure Load Balancer: Distributes network traffic across backend resources.
- Azure Application Gateway: Provides application-level web traffic routing and related protection capabilities.

African example:
Use a university with separate networks for students, staff, and administration to explain network segmentation and security.

### 2.4 Azure Storage Services

Explain:
- Azure Blob Storage: Stores unstructured data such as images, videos, documents, and backups.
- Azure Files: Provides managed file shares that can be accessed by multiple systems.
- Azure Queue Storage: Stores messages that help different application components communicate asynchronously.
- Azure Table Storage: Provides a NoSQL key-value store for structured, non-relational data.
- Azure Disk Storage: Provides persistent disks for Azure virtual machines.
- Storage redundancy: Explain LRS, ZRS, GRS, and GZRS at a beginner-friendly level.
- Storage access tiers: Explain Hot, Cool, Cold, and Archive, including their intended use cases and access-cost trade-offs.

African example:
Use a clinic storing patient documents, a photographer storing wedding videos, and a business archiving old financial records to explain different storage services and access tiers.

Explain that Archive storage is intended for rarely accessed data and that retrieving archived data can take time.

### 2.5 Identity, Access, and Security

Explain:
- Microsoft Entra ID: A cloud identity and access management service.
- Authentication: Verifying who a user is.
- Authorization: Determining what an authenticated user is allowed to do.
- Multifactor authentication (MFA): Using additional verification factors to protect accounts.
- Role-Based Access Control (RBAC): Assigning permissions according to a user's role.
- Conditional Access: Applying access rules based on relevant signals and conditions.
- Microsoft Defender for Cloud: Security posture management and workload protection capabilities.
- Microsoft Entra Domain Services: Managed domain services for supported domain-dependent workloads.
- The principle of least privilege.

African example:
Explain how a hospital can give doctors access to clinical records, accountants access to billing information, and receptionists access to appointment details without giving everyone the same permissions.

## MODULE 3: AZURE MANAGEMENT AND GOVERNANCE

Introduce Azure management and governance as the practices and tools used to control cloud spending, organize resources, enforce rules, deploy infrastructure, and monitor services.

### 3.1 Cost Management

Explain:
- Azure Pricing Calculator: Estimates the cost of planned Azure services.
- Azure Cost Management: Helps analyze and manage cloud spending.
- Budgets and alerts: Help notify users when spending approaches defined thresholds.
- Cost optimization: Identifying unnecessary resources and selecting suitable service sizes.
- Consumption-based pricing: Paying according to the resources and services consumed.
- The difference between pricing estimates and actual cloud charges.

African example:
A small Kenyan startup wants to estimate its monthly cloud bill before hosting its website and database.

Explain how the startup can estimate costs, monitor spending, and receive budget alerts.

### 3.2 Azure Governance and Compliance Tools

Explain:
- Azure Policy: Creates and evaluates rules that help ensure resources meet organizational requirements.
- Resource locks: Help prevent accidental deletion or modification of protected resources.
- Microsoft Purview: Provides data governance and related data management capabilities.
- Microsoft Defender for Cloud: Helps assess security posture and identify security recommendations.
- Management groups: Organize subscriptions for governance at scale.
- Tags: Add metadata to resources for organization, reporting, and cost allocation.

African example:
A company wants to ensure its Azure resources follow approved configurations and that its finance department can identify cloud spending by department.

Explain that governance helps organizations manage resources consistently, but does not automatically guarantee legal or regulatory compliance.

### 3.3 Azure Resource Management and Deployment Tools

Explain:
- Azure Portal: A browser-based graphical interface for managing Azure resources.
- Azure Cloud Shell: A browser-accessible shell with command-line tools for managing Azure.
- Azure CLI: A command-line tool for creating and managing Azure resources.
- Azure PowerShell: PowerShell commands for Azure administration.
- Azure Resource Manager (ARM): The deployment and management layer for Azure resources.
- ARM templates: JSON-based infrastructure-as-code templates for defining Azure deployments.
- Bicep: A declarative language for deploying Azure resources using simpler syntax than ARM JSON templates.
- Azure Arc: Helps manage supported resources across on-premises, multicloud, and Azure environments.

African example:
A beginner developer creates a virtual machine through the Azure Portal, then learns how to automate the same deployment using command-line tools or an infrastructure-as-code template.

Clearly distinguish the Azure Portal, Azure CLI, Azure PowerShell, ARM templates, and Bicep.

### 3.4 Azure Monitoring Tools

Explain:
- Azure Monitor: Collects and analyzes monitoring data from Azure resources and applications.
- Azure Service Health: Provides information about Azure service issues, planned maintenance, and relevant health advisories.
- Azure Advisor: Provides recommendations for improving reliability, security, performance, operational excellence, and cost.
- Application Insights: Helps monitor application performance, requests, failures, and dependencies.
- Log Analytics: Helps query and analyze collected log data.
- Alerts: Notify users when defined conditions are met.
- Metrics and logs: Explain the difference between numerical measurements over time and recorded event details.

African example:
A Kenyan online shop experiences slow page loading and occasional errors. Explain how monitoring tools can help the developer investigate the problem, receive alerts, and identify possible improvements.
